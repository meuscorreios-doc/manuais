Integração Shopify x MeusCorreios — Manual de Configuração

Este manual orienta como obter o domínio, o Client ID e o Client Secret no Shopify, configurar a integração no MeusCorreios e importar os pedidos para geração de pré-postagens.

A integração depende de duas etapas principais: primeiro criar/configurar o aplicativo no Shopify e depois informar os dados da integração no cadastro do remetente dentro do MeusCorreios.

Pré-requisitos

  • Acesso administrativo à loja Shopify.
  • Permissão para acessar Configurações > Apps > Desenvolver apps.
  • Acesso ao Dev Dashboard da Shopify para criar e configurar o aplicativo.
  • Acesso ao MeusCorreios com permissão para alterar as integrações do remetente.
  • Remetente já cadastrado no MeusCorreios.

1. Gerar as credenciais de acesso no Shopify

No Shopify, será necessário obter três dados principais para preencher no MeusCorreios: Domínio, client_id e client_secret.

1.1. Localizar o domínio da loja

  1. Acesse a área administrativa da loja Shopify.
  2. Entre em Configurações.
  3. Acesse o menu Domínios.
  4. Copie o domínio da loja para usar posteriormente na configuração do MeusCorreios.

1.2. Acessar o Dev Dashboard e criar o aplicativo

  1. No Shopify, acesse Configurações > Apps > Desenvolver apps.
  2. Clique em Desenvolver Apps no Dev Dashboard.
  3. No Dev Dashboard, clique em Criar APP.
  4. Informe um nome para o aplicativo. Exemplo: MeusCorreios.

1.3. Informar os escopos de acesso

Na guia Acesso do aplicativo, cole os escopos abaixo:

read_all_orders,read_assigned_fulfillment_orders,write_assigned_fulfillment_orders,write_draft_orders,read_draft_orders,write_order_edits,read_order_edits,read_orders,write_orders,read_products,write_products,read_third_party_fulfillment_orders,write_third_party_fulfillment_orders,customer_read_draft_orders,customer_read_orders,customer_write_orders
⚠️ Copie os escopos exatamente como estão, separados por vírgula e sem espaços adicionais.
  1. Após preencher os escopos, clique em Lançar.
  2. Confirme clicando novamente em Lançar.
  3. Depois, acesse Configurações do aplicativo para copiar o ID do Cliente e a Chave Secreta.
Campo no ShopifyID do Cliente
Use como client_id no MeusCorreios.
Campo no ShopifyChave Secreta
Use como client_secret no MeusCorreios.

1.4. Instalar o aplicativo criado

  1. No Shopify, acesse Apps.
  2. Clique no aplicativo criado.
  3. Clique em Instalar.
  4. Finalize a instalação para liberar o uso da integração.

2. Configurar a integração no MeusCorreios

  1. Entre no menu Configurações.
  2. Clique em Remetentes.
  3. No remetente que será usado para integrar a plataforma, clique em Integrações.
  4. Selecione a opção Integrações/Shopify.

Preencha os campos com os dados obtidos no Shopify:

Campo no MeusCorreiosO que preencher
DomínioDomínio da loja obtido em Configurações > Domínios no Shopify.
client_idID do Cliente copiado nas configurações do app Shopify.
client_secretChave Secreta copiada nas configurações do app Shopify.
Status dos pedidosStatus que o MeusCorreios irá buscar quando executar a integração.

Após preencher os dados, clique em Confirmar.

3. Geração de Pré-Postagens de Pedidos Shopify

3.1. Criar ou utilizar um lote existente

  1. Entre no módulo de Pré-postagem do MeusCorreios.
  2. Crie um novo lote ou utilize um lote já existente.
  3. Ao criar um novo lote, selecione a opção Integração Shopify.
  4. Ao utilizar um lote existente, selecione a opção Integra/Shopify.
ℹ️ A opção de integração pode ser deixada como padrão acessando Configurações > Importações e Integrações.

3.2. Definir as opções da importação

Após buscar os pedidos, os dados serão exibidos na tela. Antes de gerar a pré-postagem, defina como o MeusCorreios deve tratar os pedidos importados:

OpçãoDescrição
Pedidos já incluídos no loteDefine se pedidos já adicionados anteriormente serão desconsiderados.
AR nas postagensDefine se será incluído Aviso de Recebimento nas postagens.
Valor DeclaradoDefine se o valor do pedido será considerado como Valor Declarado.
Declaração de ConteúdoDefine se as declarações serão criadas com base nos itens de cada pedido.
Essas opções também podem ser configuradas como padrão em Configurações > Importações e Integrações.

O MeusCorreios buscará o endereçamento de cada pedido nos campos de shipping do Shopify.

3.3. Selecionar pedidos e gerar pré-postagens

  1. Selecione os pedidos pelo Destinatário, Serviço ou Faixa de Pedido, quando necessário.
  2. Marque todos os pedidos que serão postados.
  3. Use o quadrinho do cabeçalho para marcar ou desmarcar todos os pedidos da página.
  4. Alterne entre páginas sem perder os itens já marcados.
  5. Pedidos que não devem ser postados devem permanecer desmarcados.
  6. Clique em Gerar Pré-Postagem de Todos os Marcados.
⚠️ Caso o serviço já venha definido no pedido, cadastre os serviços no Dicionário de Serviços para que o MeusCorreios atribua o código corretamente. Se preferir, deixe o MeusCorreios definir o serviço na próxima etapa.

4. Selecionando Serviços e Definindo as Etiquetas

Depois de importar os pedidos pela integração, o MeusCorreios indica o que ainda falta por meio dos menus em vermelho na tela de Pré-Postagem ou dentro dos lotes gerados.

StatusO que significaAção recomendada
Sem ServiçoPedidos foram importados, mas ainda não tiveram serviço atribuído.Verifique o Dicionário de Serviços ou atribua o serviço manualmente.
Sem RegistroPedidos tiveram serviço atribuído, mas ainda não tiveram etiqueta atribuída.Verifique o estoque/range de etiquetas do serviço selecionado.
Não EmitidosPedidos tiveram serviços e etiquetas atribuídas, mas ainda não foram impressos.Imprima as etiquetas.
Sem ListaEtiquetas foram emitidas, mas a lista de postagem ainda não foi gerada.Gere a lista de postagem e envie as caixas para a agência que atende a empresa.

5. Possíveis Erros e Soluções

Erro ou situaçãoPossível causaComo resolver
A Integração retornou um Erro e não pode ser concluída! O MeusCorreios tentou acessar a integração e não conseguiu. Verifique os dados informados na configuração da integração. Também é possível gerar o log clicando em Log Pós Integração.
Serviço não atribui ao clicar em Atribui Serviços O serviço selecionado pode não ter abrangência para o CEP de destino. Verifique se o serviço possui abrangência para o CEP de destino. Exemplo: PAC local.
Atribui Serviço, mas não atribui Etiqueta Pode não haver estoque/range de etiquetas disponível para o serviço selecionado. Verifique seu estoque de etiquetas ou entre em contato com a AGF que atende sua empresa e solicite um novo range de etiquetas.
