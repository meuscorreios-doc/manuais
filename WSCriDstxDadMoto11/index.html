Visão geral

O WSCriDstxDadMoto11 cria uma pré-postagem, gera a etiqueta dos Correios e devolve o PDF da etiqueta em base64, numa única chamada. É a versão 11 do web service de criação de postagem para a Motorola, com serviços adicionais e chave da NF-e opcional.

Como o serviço funciona:

  • Serviço dos Correios: quem escolhe é o MC30, pela faixa de CEP cadastrada para o grupo. O cliente não informa o serviço, e o código escolhido volta em Codectcod.
  • Lote: as postagens do dia de cada unidade ficam num lote “WS”. Passando de 300 postagens, abre-se um lote novo.
  • Reenvio da mesma NF: se a Dstxnfi já foi enviada por essa unidade hoje ou ontem, nada novo é criado. O serviço devolve a etiqueta e o PDF da postagem que já existe, então reenviar após um timeout é seguro.
  • Dimensões: a postagem sempre é gravada com 16 × 16 × 16 cm. Os valores de Dstxvo1, Dstxvo2 e Dstxvo3 são ignorados.
  • Valor declarado: se existir uma faixa de valor declarado para o CEP de destino, o valor dela substitui o Dstxvd informado (código 13).

Autenticação

No corpo de cada chamada vão três campos: o login e a senha do usuário no meuscorreios.app e o código da unidade dentro do grupo empresarial. Não há token nem cabeçalho de autenticação.

  1. Webcliema e Webclisen são conferidos como no login da tela. Se falharem, a resposta traz Erro = “Usuário ou Senha Inválido” (ou a mensagem do login).
  2. O grupo empresarial é o do e-mail Webcliema. Se o e-mail não pertencer a um grupo, a resposta é o código 2.
  3. Grpusrcod define a unidade (cliente) em nome de quem a postagem é criada. Se a unidade não for do grupo, a resposta é o código 3.
  4. A unidade precisa ter exatamente um cartão de postagem: sem cartão é o código 4, e com mais de um é o código 14.

No cadastro da unidade, o parâmetro LIBIMP = S deixa a postagem liberada para impressão assim que a etiqueta é gerada.

Erros e códigos de retorno

O resultado sai em Errocod e Erro. Considere sucesso apenas quando Errocod = 0 e Erro vier vazio, ou quando Errocod = 13.

Dois erros voltam com Errocod = 0 e só a mensagem preenchida (linhas marcadas com “0*”). Confira sempre o campo Erro.
