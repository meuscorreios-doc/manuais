Integração Wbuy x MeusCorreios — Manual de Configuração

Este manual orienta como obter o Usuário API e a Senha API no painel da Wbuy, configurar a integração no MeusCorreios, importar os pedidos para geração de pré-postagens e acompanhar o retorno automático de rastreio para a Wbuy.

A integração depende de duas etapas principais: primeiro gerar as credenciais de API no painel da Wbuy, e depois informar esses dados no cadastro do remetente dentro do MeusCorreios. Uma vez configurada, a integração é bidirecional: o MeusCorreios importa os pedidos da Wbuy e, ao gerar/atualizar o rastreio, devolve automaticamente o código de rastreio e o status para a Wbuy — sem passo manual adicional.

Pré-requisitos

  • Acesso administrativo ao painel da Wbuy.
  • Permissão para acessar Plataforma > API e Webhooks na Wbuy.
  • Acesso ao MeusCorreios com permissão para alterar as integrações do remetente.
  • Remetente já cadastrado no MeusCorreios.
  • Conhecer os códigos de status de pedido usados na loja Wbuy (para preencher os filtros de status na integração).

1. Gerar as credenciais de acesso na Wbuy

No painel da Wbuy, será necessário gerar um Usuário API e uma Senha API para preencher no MeusCorreios.

  1. Acesse o painel administrativo da sua loja Wbuy.
  2. No menu lateral, acesse Plataforma > API e Webhooks.
  3. Acesse Opções > Integração REST API.
  4. Crie uma nova chave, informando uma identificação para reconhecer depois (por exemplo, MeusCorreios).
  5. Copie o usuário gerado.
  6. Clique em Visualizar senha e copie a senha exibida.
⚠️ A API da Wbuy limita 100 requisições a cada 60 segundos por credencial. Se a integração for usada por mais de um sistema simultaneamente com a mesma credencial, considere gerar uma chave exclusiva para o MeusCorreios.
Campo na WbuyUsuário
Use como Usuário API no MeusCorreios.
Campo na WbuySenha
Use como Senha API no MeusCorreios.

2. Configurar a integração no MeusCorreios

  1. Entre no menu Configurações.
  2. Clique em Remetentes.
  3. No remetente que será usado para integrar a plataforma, clique em Integrações.
  4. Selecione a opção Integrações/Wbuy.

Preencha os campos com os dados obtidos na Wbuy e defina os status que a integração deve considerar:

Campo no MeusCorreiosO que preencher
Usuário APIUsuário copiado em Plataforma > API e Webhooks na Wbuy.
Senha APISenha copiada em "Visualizar senha" na mesma tela.
Pedidos com Cód. StatusCódigo de status da Wbuy que a integração deve buscar ao importar pedidos.
Tag / Identificador opcionalFiltra os pedidos por um identificador/tag específico da Wbuy, quando necessário.
Status "Enviado"Código de status que a Wbuy deve receber quando a postagem for confirmada como enviada.
Status "Entregue"Código de status que a Wbuy deve receber quando o objeto for confirmado como entregue.

Após preencher os dados, clique em Confirmar.

3. Geração de Pré-Postagens de Pedidos Wbuy

3.1. Criar ou utilizar um lote existente

  1. Entre no módulo de Pré-postagem do MeusCorreios.
  2. Crie um novo lote ou utilize um lote já existente.
  3. Ao criar um novo lote, selecione a opção Integração Wbuy.
  4. Ao utilizar um lote existente, selecione a opção Integra/Wbuy.
ℹ️ A opção de integração pode ser deixada como padrão acessando Configurações > Importações e Integrações.

3.2. Definir as opções da importação

Após buscar os pedidos, os dados serão exibidos na tela. Antes de gerar a pré-postagem, defina como o MeusCorreios deve tratar os pedidos importados:

OpçãoDescrição
Pedidos já incluídos no loteDefine se pedidos já adicionados anteriormente serão desconsiderados.
AR nas postagensDefine se será incluído Aviso de Recebimento nas postagens.
Valor DeclaradoDefine se o valor do pedido será considerado como Valor Declarado.
Declaração de ConteúdoDefine se as declarações serão criadas com base nos itens de cada pedido.
Essas opções também podem ser configuradas como padrão em Configurações > Importações e Integrações.

O MeusCorreios busca o endereçamento, o frete (nome e valor) e o peso de cada produto direto no pedido da Wbuy. Se o pedido já tiver um código de rastreio atribuído na própria Wbuy, o MeusCorreios reaproveita esse código automaticamente.

3.3. Selecionar pedidos e gerar pré-postagens

  1. Selecione os pedidos pelo Destinatário, Serviço ou Faixa de Pedido, quando necessário.
  2. Marque todos os pedidos que serão postados.
  3. Use o quadrinho do cabeçalho para marcar ou desmarcar todos os pedidos da página.
  4. Alterne entre páginas sem perder os itens já marcados.
  5. Pedidos que não devem ser postados devem permanecer desmarcados.
  6. Clique em Gerar Pré-Postagem de Todos os Marcados.
⚠️ Caso o serviço de frete já venha definido no pedido da Wbuy, cadastre os serviços no Dicionário de Serviços para que o MeusCorreios atribua o código corretamente. Se preferir, deixe o MeusCorreios definir o serviço na próxima etapa.

4. Selecionando Serviços e Definindo as Etiquetas

Depois de importar os pedidos pela integração, o MeusCorreios indica o que ainda falta por meio dos menus em vermelho na tela de Pré-Postagem ou dentro dos lotes gerados.

StatusO que significaAção recomendada
Sem ServiçoPedidos foram importados, mas ainda não tiveram serviço atribuído.Verifique o Dicionário de Serviços ou atribua o serviço manualmente.
Sem RegistroPedidos tiveram serviço atribuído, mas ainda não tiveram etiqueta atribuída.Verifique o estoque/range de etiquetas do serviço selecionado.
Não EmitidosPedidos tiveram serviços e etiquetas atribuídas, mas ainda não foram impressos.Imprima as etiquetas.
Sem ListaEtiquetas foram emitidas, mas a lista de postagem ainda não foi gerada.Gere a lista de postagem e envie as caixas para a agência que atende a empresa.

5. Retorno automático de rastreio para a Wbuy

Diferente de uma simples importação, a integração com a Wbuy é bidirecional: depois que uma etiqueta é atribuída e o status do objeto muda no MeusCorreios, o código de rastreio e o status configurado são enviados de volta para a Wbuy automaticamente — não é necessário nenhum passo manual para isso.

Evento no MeusCorreiosO que é enviado para a Wbuy
Objeto passa para o status configurado em Status "Enviado"Código de rastreio, nome do serviço de frete e link de rastreamento.
Objeto passa para o status configurado em Status "Entregue"Confirmação de entrega no status configurado.
ℹ️ Se o retorno para a Wbuy falhar (por exemplo, usuário/senha inválidos ou pedido não encontrado), o erro fica registrado no Log Pós Integração do pedido, sem impedir a postagem em si.

6. Possíveis Erros e Soluções

Erro ou situaçãoPossível causaComo resolver
A Integração retornou um Erro e não pode ser concluída! O MeusCorreios tentou acessar a API da Wbuy e não conseguiu. Verifique o Usuário API e a Senha API cadastrados. Também é possível gerar o log clicando em Log Pós Integração.
Erro 429 / limite de requisições A credencial excedeu o limite de 100 requisições a cada 60 segundos na Wbuy. Aguarde alguns instantes e tente novamente. Se o volume de pedidos for muito alto, gere uma credencial exclusiva para o MeusCorreios.
Serviço não atribui ao clicar em Atribui Serviços O serviço selecionado pode não ter abrangência para o CEP de destino. Verifique se o serviço possui abrangência para o CEP de destino. Exemplo: PAC local.
Atribui Serviço, mas não atribui Etiqueta Pode não haver estoque/range de etiquetas disponível para o serviço selecionado. Verifique seu estoque de etiquetas ou entre em contato com a AGF que atende sua empresa e solicite um novo range de etiquetas.
Retorno de rastreio para a Wbuy não aparece no pedido O pedido pode ter sido excluído/alterado na Wbuy após a importação, ou a credencial perdeu acesso. Confira o Log Pós Integração do pedido e revalide o Usuário API / Senha API cadastrados no remetente.
