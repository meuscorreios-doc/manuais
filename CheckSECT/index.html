Checklist Venda Balança Cubadora SECT

Este passo a passo é voltado para a segurança da postagem. O processo é mais lento porque inclui as telas de conferência disponíveis em cada etapa da venda, permitindo identificar pendências antes de concluir a expedição.

Objetivo: garantir que os objetos pesados na balança sejam vendidos no SECT, atualizados no Correios Atende, conferidos no SRO e expedidos sem pendências.

Checklist operacional

Marque cada item conforme concluir a etapa.

Procedimento detalhado

1. Pesagem dos objetos

  1. Realize normalmente a pesagem dos objetos na balança.
  2. Se o WS informar “Não Localizado”, significa que não foi encontrada uma pré-postagem com os dados informados.
  3. Nesse caso, puxe o arquivo do MeusCorreios. Se o objeto for de terceiros, solicite ao cliente o ajuste da pré-postagem.
Em versões do WS posteriores a 11/08/2026, o sistema também avisa quando o cartão está suspenso, inativo ou cancelado. Entre em contato com o cliente para informar o problema no contrato. Após o ajuste, utilize Situação dos Objetos para puxar a PPN e prosseguir com a venda.

2. Venda no CTRL+S do SECT

  1. Faça a venda no CTRL+S.
  2. Acesse a tela Situação da Balança e confira se ficaram objetos pendentes para venda.

Se algum objeto aparecer nessa tela com o campo PLP vazio, a PPN do arquivo não foi importada. Clique em Buscar SVP/PPN para criar o arquivo necessário à venda. É nessa etapa que podem ser recuperadas as PPNs de objetos que apresentaram erro durante a pesagem, como cartão suspenso.

3. Conferência no Monitor SIGEPweb

Após a venda no CTRL+S, o SECT envia os dados ao Monitor SIGEPweb, responsável pela atualização da venda no Correios Atende.

  1. O monitor atualiza automaticamente a cada 5 minutos. Para forçar uma atualização, pressione F5 ou clique no ícone de atualizar.
  2. O comportamento normal é os objetos desaparecerem do monitor conforme passam a constar como postados no SRO.
  3. Se um objeto não desaparecer, pode ser que o Correios Atende ainda não tenha atualizado a informação.
  4. Se o CA estiver com problema, utilize a API SARA dentro de SECT x Postados SRO para confirmar se existe realmente algum objeto sem postagem.
  5. Para reprocessar um objeto que ainda não consta como postado no CA, informe a letra V. O monitor enviará novamente os dados daquela postagem.

4. Conferência no SECT x Postados SRO

Esta é a tela mais importante do processo. Ela mostra objetos postados no SECT que ainda não constam como postados no SRO. Consulte esta tela durante e depois do processo de venda.

Acesse Expedição → SECT x Postados SRO.

5. Gerar o arquivo e realizar a expedição no SROweb

A configuração da expedição no SECT está detalhada no manual Expedição no SECT.
  1. Após a postagem no Correios Atende, aguarde o retorno da informação POSTADO. O arquivo de expedição somente é gerado depois desse retorno.
  2. Antes de gerar o arquivo, deixe os rótulos abertos no SROweb.
  3. Acesse Expedição → SECT x Expedidos SRO ou utilize ALT+X.
  1. Confirme se todos os objetos possuem numeração preenchida na coluna Pos.
  2. Clique em Arquivo SRO.
  1. Com o robô de expedição instalado e configurado, abra o programa e clique em Iniciar Processo.
  2. O robô direcionará o processo para o SROweb e iniciará a leitura dos objetos.
Atenção: só existirá arquivo para envio se houver retorno da informação POSTADO.

Conclusão da conferência

Antes de encerrar o procedimento, confirme que não existem pendências de venda na balança, que as postagens foram atualizadas no Correios Atende/SRO e que o arquivo de expedição foi processado pelo robô.

Se houver diferença entre o SECT e o SRO, utilize primeiro as ferramentas de conferência da tela SECT x Postados SRO — especialmente Pesados s/ Venda, Não Finalizadas e API SARA — antes de considerar o processo concluído.
